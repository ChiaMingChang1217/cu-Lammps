# Multi-nanovoid copper molecular dynamics and machine learning

Research data and code supporting **Initial void size effects on peak stress and postpeak load retention in multi-nanovoid copper** (submitted to Computational Materials Science).

## Scope
512 production tensile simulations: four nominal radii (3, 5, 7, 9 angstrom), four target porosities (0.05, 0.10, 0.15, 0.20), four temperatures (100, 300, 500, 700 K), four strain rates (2.5e10, 5e10, 1e11, 2e11 per second), and two stochastic realizations. Four additional trajectory reruns are supplied separately and are never included in surrogate training or validation.

## Files
- `data/`: four original summary tables and 512 case folders with stress-strain histories, generated LAMMPS inputs, pore centers, metadata, logs and available per-case summaries.
- `analysis/`: descriptor extraction, grouped cross-validation, regression, plotting and OVITO scripts; reported numerical outputs.
- `analysis/trajectories/`: four complete gzip-compressed atom trajectories, their LAMMPS inputs, stress histories and run reports. OVITO reads the compressed files directly. Each contains 31 frames.
- `reference_results/`: unchanged reported analysis tables, fold assignments, predictions and empirical coefficients for comparison after rerunning analysis.
- `simulation/`: original simulation-generation and extraction scripts and the four production scan tables.

## Download and unpack
Download this repository or clone it, then run `python unpack_data.py` once. Production records are stored in 32 ZIP archives; complete compressed trajectories are split into numbered binary parts for transfer. The unpacker restores the paths used by the analysis scripts without changing numerical data. Run OVITO rendering before assembling the atomic figures.

## Reproduce numerical analyses
Install Python with numpy, pandas, matplotlib and scikit-learn. Package versions of the local validation environment are recorded separately. From this repository root run:

```sh
python analysis/analyze_extension.py
python analysis/model_extension.py
python analysis/audit_relaxation.py
```

These scripts write outputs under `analysis/`; preserved reported values remain in `reference_results/`. Plotting may vary between package versions. Original stress-strain files and inputs remain unchanged. The main analysis paths have been made repository-relative.

For trajectory analysis install OVITO and run `python analysis/render_ovito.py`, then `python analysis/assemble_figures.py`. The OVITO calculation uses an affine mapping to the reference cell and PTM RMSD cutoff 0.10. It is not a D2min calculation. Map tiles are regenerated by render_ovito.py.

## Rerun LAMMPS
Generated inputs preserve the original run, including historical absolute potential and output paths. Before running an input in a new case directory, change `pair_coeff` to your local Cu_u3.eam file and the `fix csv` output path to `stress_strain.csv`. Preserve every other simulation parameter. Set LAMMPS_EXE and LAMMPS_POTENTIALS when using the simulation utilities. LAMMPS executables and third-party software are not bundled. See `simulation/potentials/README.md` for the exact potential checksum and source.

## Descriptor definitions and limitations
S is peak axial virial stress and I is its strain integral over the shared engineering-strain interval 0.001 to 0.2995. R is final-window stress divided by S. I is an integrated response descriptor, not rigorously work-conjugate energy or fracture toughness. Actual porosity denotes the initially removed-atom fraction, not equilibrated void volume. Nominal pore radius, pore number and surface density vary together. Trajectory reruns support interpretation and are not independent production cases.
